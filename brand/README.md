# Paquete de traspaso · Identidades G-MoRE

Copia esta carpeta en tu repo (por ejemplo en `brand/`) y dile al agente que lea
`BRAND.md` antes de empezar. Puedes referenciarlo desde tu `CLAUDE.md` / `AGENTS.md`.

- `reference/*.html`: abre cualquiera en el navegador para ver la identidad tal cual está en el lienzo.
- `identities.json` y `tokens.css`: los valores exactos de cada identidad.
- `assets/`: logos y símbolos recortados de las fichas.
- `sheets/`: las fichas originales.
- `source/`: plantilla y scripts originales (solo trazabilidad; las rutas internas apuntan al entorno donde se generaron).
